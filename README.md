# ねこアーチャー

止まると撃つ、猫のローグライト・アクション（ブラウザ / スマホ縦向き）。

- 指をすべらせて移動。止まると いちばん近い虫へ 自動で毛玉を撃つ
- 1章は10ステージ（5 と 10 はボス）。敵を全部たおすと 上の扉が開く
- レベルが上がるたびに スキルを3つから1つえらぶ（プレイが終わると消える）
- にぼし（お金）と装備は ずっと残る。装備は 強化と、同じもの3つの合成で育てる

## 開発

```sh
npm install
npm run dev     # 遊ぶ
npm test        # テスト（バランスの目安もふくむ）
npm run build   # dist に出力
```

## つくり

- `src/core/` … データと計算（スキル・装備・ステージ・セーブ・結果）。画面に依存しない
- `src/game/world.ts` … 戦闘の計算（テストでそのまま動く）
- `src/game/render.ts` … 戦闘の絵（猫は `public/cat/` の PNG、虫はコードで描く）
- `src/ui/` … 画面（戦闘・装備）と効果音
- `tests/bot.ts` … バランス確認用の かんたんなプレイヤー
