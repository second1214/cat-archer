Artifacts[edit | edit source]
You are guaranteed a Legendary or Mythic Artifact if you unsuccessfully find one within 100 wishes. Pull % can be found on Pull Rates
Each Artifact can be increased to 15 Star which increases the Artifacts base stats. Each Star adds +50% base stats.
You can find all available Archero 2 Artifacts in the following tables including the Base Stats and if applicable Special Stats (Epic Artifacts or higher)
There are also set bonus's which are below the lists
