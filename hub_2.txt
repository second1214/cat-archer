How to use the Artifact Codex
Artifacts are a permanent stat layer that operates separately from your character roster. Once activated and starred up, they apply to whichever character you bring into combat, making them a steady long-term investment even when you swap mains.
Each artifact has a rarity (Rare / Epic / Legendary / Mythic) and may belong to a set. Owning all artifacts of a set unlocks a set bonus whose strength is gated by the lowest ★ across the set members — so evenly leveling all set pieces beats over-investing a single one.Read more
This codex lists all 14 sets plus the standalone artifacts that sit outside any set. Each card shows the rarity, individual flavor, and the set-effect ★ schedule so you can quickly decide which sets to chase.
Shard requirements per ★ are tracked on the “Artifact Shards” page; the final impact on your build can be simulated in the “Stat Calculator”.
FAQ
QHow do set bonuses activate?
Owning all artifacts in a set activates the bonus. Its strength is keyed to the lowest ★ across the set members, so balanced star-up beats focusing on a single piece.QSingle mythic vs. a full legendary set — which is better?
A single mythic gives you the largest individual stat boost but no set bonus. A complete legendary set provides stacked ATK/HP % from set effects. Most builds layer both: complete legendary sets first, then add a mythic standalone on top.QHow do standalone artifacts fit in?
Standalones do not contribute to set bonuses but their personal effects are strong. Pick the standalones that match your build direction (offense, survivability, or a specific skill synergy) from the “Standalone Artifacts” section.QWhen are new artifacts added to the codex?
New artifacts are added shortly after each major patch. The in-game tooltip is authoritative for the very latest releases; this page is for one-screen comparison and planning.
